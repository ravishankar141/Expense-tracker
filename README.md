# Spendly 

Spendly is a personal expense tracking web application currently under development.

The goal of Spendly is to provide a simple and organized way to record, manage, and track personal expenses.

## 🚧 Project Status

**Status: In Development**

The project structure and initial backend/database setup are currently being developed. More features will be added as development progresses.

## 🎯 Project Goals

Spendly aims to provide:

- Add and manage personal expenses
- Categorize expenses
- View and track spending
- Store expense data securely
- Provide a simple and clean user interface
- Make expense management easier for everyday use

## 🛠️ Tech Stack

- **Python**
- **Flask**
- **SQLite**
- **HTML**
- **CSS**
- **JavaScript**
- **Jinja2**
